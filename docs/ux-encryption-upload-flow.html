Key UX Details

Encryption State: Shows immediately after file selection, before upload begins. Uses spinner animation and progress indicator. Estimated time: 2-5 seconds for typical video sizes (50-500 MB).

Security Message: "Encrypting video for secure upload..." clearly communicates the security step to users, building trust in data protection.

Visual Feedback: Blue color scheme (#2563eb) indicates security/encryption process. Green (#10b981) indicates successful upload progress.
