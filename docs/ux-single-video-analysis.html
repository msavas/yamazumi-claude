💡 Single Video Analysis View
This view focuses on analyzing individual work elements from a single video. The stacked bar chart shows the breakdown of waste, non-value-added, and value-added work. Notice the ghost vs solid states - unverified AI suggestions appear in ghost state (50% opacity, dashed borders), while verified elements appear solid. The takt time line does NOT appear in this view - it's only shown in factory-wide Yamazumi views where rebalancing across multiple stations is the focus.
Single Video Analysis Features

Note: Takt time line does NOT appear in single video analysis view. It only appears in factory-wide Yamazumi views (macro and micro views) where rebalancing across multiple stations is the focus.

Ghost vs Solid States:

  • Ghost state (50% opacity, dashed): Unverified AI suggestions
  • Solid state (100% opacity, solid): Verified/user-overridden data
  • Click any segment to verify + cycle category

Draft & Commit Workflow:

  • "Accept All" button for bulk verification
  • Click-to-cycle for individual corrections
  • Right-click for AI reasoning tooltips
