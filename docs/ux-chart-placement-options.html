2. Factory Hierarchy Selection

How should users select which factory level to view in Yamazumi charts?

Option 1: Dropdown Selector
Simple dropdown menu showing hierarchy levels. Select one level to view.
Select View Level
Current Selection:
Section A > Main Line

Pros:

  • Simple and familiar
  • Takes minimal space
  • Easy to implement

Considerations:

  • Hard to see full hierarchy at once
  • Can't easily compare levels
  • Nested options can be long
Option 2: Tabs
Tab interface showing different hierarchy levels. Switch between tabs to view different levels.
View Level
Viewing: Main Line
Shows all stations in Main Line

Pros:

  • Quick switching between levels
  • Visual indication of current level
  • Good for horizontal hierarchy

Considerations:

  • Limited to few levels (tabs get crowded)
  • Can't see hierarchy structure
  • Hard to compare multiple levels
Option 3: Hierarchical Tree
Expandable tree showing full factory structure. Click nodes to view that level. Multi-select for comparison.
Factory Structure
▼ 🏭 Entire Factory
▼ 📦 Section A
▶ 📊 Main Line

💡 Tip: Select multiple nodes to compare side-by-side

Pros:

  • Shows full hierarchy structure
  • Easy to navigate and understand
  • Supports multi-select for comparison
  • Scalable to any hierarchy depth
  • Visual representation of factory structure

Considerations:

  • Takes more space than dropdown
  • More complex to implement
  • Might be overkill for simple factories

💡 Recommendations

Chart Placement: Option B (Chart Replaces Sidebar) works best with Direction 2 (Dense Dashboard). The side-by-side layout allows users to watch video and see chart simultaneously, and the toggle keeps the interface clean.

Hierarchy Selection: Option 3 (Hierarchical Tree) provides the most flexibility and aligns with your requirement for modular, hierarchical viewing. It supports multi-select for side-by-side comparison and scales to any factory size. For simpler factories, the tree can be collapsed to show only relevant levels.
