Macro/Micro Aggregation Specifications

Chart Orientation:

  • Factory-Wide View: Vertical stacked bar charts (traditional Yamazumi format)
  • Single Video Analysis: Horizontal stacked bar charts (better for single video UX)

View Toggle:

  • Waste/NVA/Value View: Shows aggregated categories per station (traditional view)
  • Work Elements View: Shows individual work elements within each station (rebalancing view)
  • Toggle between views to see different perspectives

Work Element Interactions:

  • Hover: Tooltip shows waste/NVA/value breakdown for that work element
  • Click: View video clip of that work element
  • Enables rebalancing analysis - see which work elements can be moved between stations

Rationale: Vertical charts are traditional for Yamazumi and better for comparing multiple stations. Work element view enables rebalancing analysis by showing which elements can be moved between stations. Hover tooltips provide quick insight without leaving the macro view.
