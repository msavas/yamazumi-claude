Zoom & Pan Specifications

Zoom Controls:

  • Zoom Slider: Drag to adjust zoom level (10% to 200%)
  • Zoom Buttons: Click + to zoom in, - to zoom out
  • Fit to Screen: Automatically adjusts zoom to show all stations
  • Mouse Wheel: Scroll to zoom in/out (centered on cursor)

Pan & Navigation:

  • Click & Drag: Pan the chart to navigate
  • Minimap: Click or drag the viewport box to jump to different areas
  • Arrow Keys: Pan left/right/up/down
  • Station Click: Click a station to zoom into work elements (micro view)

Zoom Levels:

  • 10-30%: See entire factory (50+ stations) - perfect for identifying bottlenecks
  • 50-75%: See 10-20 stations with detail - good for analyzing sections
  • 100-200%: See 3-8 stations with full detail - focus on problem areas

Takt Time Line:

  • Visual Style: Horizontal red dotted line across chart
  • Position: Based on takt time value (e.g., 45 seconds)
  • Label: "Takt Time: 45s" displayed on right side (updates in real-time as line is dragged)
  • Interpretation: Stations above line = bottlenecks (over takt time), Stations below line = extra capacity (under takt time)
  • Interaction: Drag line up/down to adjust takt time value for "what if" scenarios
  • Live Update: Seconds value updates in real-time as line is dragged
  • Auto-Snap: When user selects a Line, line automatically snaps to that Line's takt time value
  • Data Model: Takt time is a Line-level property (stored at Line level in database, not Station level)
  • Cursor: Changes to "grab" (open hand) when hovering, "grabbing" (closed hand) when dragging
  • Purpose: Enables rebalancing analysis - identify which stations need kaizen or can take on more work

Rationale: Large factories need both overview and detail views. Zoom out to see the full picture and identify bottlenecks, then zoom in to analyze specific problem areas. The minimap provides spatial context and quick navigation. The takt time line is critical for rebalancing - it shows which stations exceed the target and which have capacity for additional work elements.
