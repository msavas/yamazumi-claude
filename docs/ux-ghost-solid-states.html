Visual State Specifications

Ghost State (Unverified AI Results):

  • Opacity: 50% (`opacity: 0.5`)
  • Border: Dashed (`border-style: dashed`, 2px width)
  • Low Confidence Indicator: "?" icon badge appears if confidence < 0.7
  • Applied to: Timeline segments, chart segments, work element list items
  • Source: `AI_ESTIMATE`, `isVerified: false`

Solid State (Verified/User Override):

  • Opacity: 100% (`opacity: 1.0`)
  • Border: Solid (`border-style: solid`, 2px width)
  • No "?" icon badge
  • Applied to: All user-verified or user-overridden segments
  • Source: `USER_OVERRIDE` or `AI_ESTIMATE` with `isVerified: true`

Rationale: Ghost state signals "this is AI's best guess, please verify" while solid state signals "this is confirmed data." The visual distinction helps users quickly identify what needs review and builds trust in AI accuracy.
